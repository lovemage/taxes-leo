# 0.1.6 — 位置策略與 Open 尺寸

- 翻後策略新增翻前位置、OOP／IP／多人中間位置、本街行動與持續下注歷史條件。可以分別設定先過牌，以及被下注後的 check-raise 頻率。
- 位置限定覆寫優先於通用規則；單節點／批次恢復支援新節點。完整度只計通用節點，不把部分位置當成全部覆蓋。
- Hero 與各 Bot 可設定各自的 Open 尺寸，也可依翻前位置覆寫。以 BB 輸入，0 表示繼承，非零範圍為 2～100 BB；畫面顯示籌碼取整值，執行時依合法加注與餘額限制。
- 後續回應尺寸依實際前方下注額換算，尺寸設定寫入執行快照。
- 持續下注歷史區分翻牌 C-bet、轉牌第二槍、河牌第三槍與延遲 C-bet；加注後取得主動權不誤標成原進攻者第二槍。
- 面對下注改為五個明確區間：≤1/3、>1/3～1/2、>1/2～2/3、>2/3 且 <1 池、≥1 池。舊快照保留原近似桶語意。
- UI 已加入 0.1.6 更新說明，沿用太空艙儀表板與既有牌桌重播動畫／音效。
- 修復瀏覽器版指定底牌分類預覽的空白解碼。

## Windows 下載

- `9max-sim-0.1.6-setup.exe`：一般安裝程式。
- `9max-sim-0.1.6.msi`：MSI 安裝套件。
- `9max-sim-0.1.6-portable.exe`：免安裝執行檔；需要 Microsoft Edge WebView2 Runtime。

安裝檔尚未數位簽章。翻後內容仍為工程基準，未經顧問簽核；策略覆寫保存在目前視窗，執行時凍結至 run 快照，命名策略庫尚未實作。
